# **Practical exercise:**

#### Custom Hook: Fetch Data

Build a custom React hook that fetches data from an API.

---

### **API to Use**

> https://jsonplaceholder.typicode.com/posts

---

### **Requirements**

1. Create a custom hook called `useFetchAPi`
2. The hook should:

- fetch data from the API
- handle:
  - loading state
  - error state

1. Return:

- `data`
- `loading`
- `error`

---

### **In your component:**

- Use the hook
- Display:
  - "Loading..." while fetching
  - Error message if failed
  - List of posts

---

### **Goal of the Exercise**

- Custom hooks
- Data fetching
- State management
